## Status Terms

- `tracked preview`: repository test scenario ile olculen 0.9 preview davranisi.
- `explicit unsupported`: initialize/capability cevabinda desteklenmedigi
  aciklanan veya 0.9 matrixinde bilerek kapsam disi tutulan yuzey.
- `advertised-unverified`: initialize cevabinda gorunen veya handler'da var olan,
  fakat tracked scenario ile olculmeyen yuzey. PASS degildir.
- `not tested`: 0.9 preview matrixinde kanit yok; destek vaadi degildir.

## Known Gaps for 0.9.0

- This matrix is preview evidence only. It does not close the later 1.0 LSP/DAP
  capability contract decision.
- No editor integration smoke is included.
- LSP references and document-highlight are advertised but unverified by tracked
  scenarios; they must not be treated as PASS until a scenario exists.
- Formatting, semantic tokens, code actions and workspace symbol are not part
  of the 0.9 preview surface.
- DAP evaluate is only measured for the hover/variable expressions used by the
  tracked scenarios; generic REPL/evaluate semantics are not claimed.
