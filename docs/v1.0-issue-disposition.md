# v1.0 Issue Disposition Kaydı

**Tarih:** 2026-07-25  
**Dayanak:** ADR-042 ve `docs/v1.0-kapsam-bildirgesi.md`  
**Kapsam:** Denetim anında açık olan 44 GitHub issue

Bu kayıt, issue kapanışını “özellik tamamlandı” kanıtı saymaz. Buradaki sınıf
ürün önceliğidir; teknik durum dört aşamalı DoD ile ayrıca tutulur.

## Sınıflar

- **V1-BLOCKER:** v1 sözleşmesini veya doğrulama programlarını doğrudan engeller.
- **V1-KARAR:** ürün sahibinin yüzey/kapsam kararı gerekir.
- **V1-KANIT:** release doğrulama altyapısıdır; tek başına özellik değildir.
- **EXPERIMENTAL:** kodda kalabilir, v1 stabil sözleşmesine dahil değildir.
- **POST-V1:** değerli olabilir; v1 release kuyruğuna giremez.
- **YENİDEN-DOĞRULA:** önce temiz revizyon ve güncel binary ile iddia tekrar
  üretilmelidir.
- **SUPERSEDED/KAPAT:** yeni ürün sözleşmesi veya daha güncel issue tarafından
  geçersiz kılınmıştır.

## Issue yazım yönetmeliği

Her aktif issue aşağıdaki alanları taşır:

- **Ürün sınıfı:** V1-BLOCKER / V1-KARAR / V1-KANIT / EXPERIMENTAL / POST-V1.
- **DoD durumu:** Tasarlandı / Uygulandı / Test Edildi / Release Edildi.
- **Kaynak revizyonu:** iddianın ölçüldüğü commit.
- **Kabul kriteri:** kullanıcıya görünen ölçülebilir sonuç.
- **Kanıt:** tracked test yolu, komut, exit code ve gerekiyorsa artifact.
- **Kapsam dışı:** issue'nun yanlışlıkla büyümemesi için açık sınırlar.

Bir issue aynı anda gelecek vizyonu, uygulama prompt'u, test raporu ve release
ilanı olamaz. Büyük hedefler karar, uygulama ve kanıt kayıtlarına bölünür.
